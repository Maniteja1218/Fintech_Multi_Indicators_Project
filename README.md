# Fintech_Multi_Indicators_Project
A Python-driven technical analysis trading strategy developed for ONGC (NSE: ONGC) that utilizes multiple indicators such as SMA, EMA, RSI, MACD, and Bollinger Bands to analyze market trends. The system generates automated BUY, SELL, and HOLD signals, maintains a tradebook for executed trades, and provides visualizations for better interpretation of results.
